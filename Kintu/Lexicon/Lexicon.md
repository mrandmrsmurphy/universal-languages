# Lexicon

> Parent: [[Kintu]] · Basic list: [[Swadesh]] · Sounds: [[Kintu/Phonology]] · Script: [[Kintu/Orthography]] · Grammar: [[Kintu/Morphosyntax]]

Dictionary of Kintu roots, one file per word, each derived from its Proto-Bantu source (BLR3 reconstructions) by the ordered rules in [[Kintu/Phonology#From Proto-Bantu]]. Tone is phonemic on roots, so the file name is the tone-marked spelling; words differing only in tone get separate files. Nouns are entered in the singular with their class pair; verbs as stem + final **-a** (the infinitive is regular: **ku-** + stem). Roots themselves are documented in [[Kintu/Roots/Roots]].

Derivation is regular and expected: every root should be run through the full machinery (noun-class mobility, the seven verb extensions, agentive **-i**, deverbal **-o**) and each natural result gets its own entry. Derivations without a daughter-language precedent carry the flag “plausible extension, not directly attested”.

## Entry format

Title is the tone-marked form, followed by a table with these rows (omit a row that doesn't apply):

| Row | Content |
| --- | --- |
| IPA | Per [[Kintu/Phonology]], tone marked |
| Part of speech | |
| Gloss | English meaning |
| Class | Noun-class pair, with the plural form |
| Root | Link to the root in [[Kintu/Roots/Roots]] |
| Proto-Bantu | Source form (BLR3) |
| Composition | Parts of a derived form, with glosses |
| Cognates | Reflexes in the daughter languages |
| Etymology | Source chain for loanwords, in place of Proto-Bantu |
| Swadesh | № in [[Swadesh]], if any |
