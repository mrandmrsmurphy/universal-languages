# -bá

> Parent: [[Kintu/Roots/Roots]]

| | |
| --- | --- |
| IPA | /bá/ |
| Gloss | enclosure, house, yard |
| Proto-Bantu | \*-bá (H) — BLR3: zones E F G M N S |
| Words | [[Kintu/Lexicon/mbá\|mbá]] (cl 9, house), [[Kintu/Lexicon/kubá\|kubá]] (cl 17, home) |

The class-9 nasal prenasalizes the initial: n + b → mb. Class 17 gives the lexicalized locative “home”, as in the daughters (compare Zulu *ekhaya*, a locative-class form).
