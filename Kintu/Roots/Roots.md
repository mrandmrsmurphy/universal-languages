# Roots

> Parent: [[Kintu]] · Words: [[Kintu/Lexicon/Lexicon]] · Sounds: [[Kintu/Phonology]]

The root inventory of Kintu, one file per root. A root is the tone-bearing core of a word: noun and verb class prefixes, extensions and final vowels attach to it (see [[Kintu/Morphosyntax]]). Every root is specified high or low; tone is phonemic here and here only, so the file name is the tone-marked root without its hyphen.

Words built on each root are listed in the root's entry and live in [[Kintu/Lexicon/Lexicon]].
