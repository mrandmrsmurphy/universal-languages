# Orthography

> Parent: [[Kintu]]

Kintu is written in the Latin alphabet as an interim orthography. The eventual script is [Ditema tsa Dinoko](https://en.wikipedia.org/wiki/Ditema_tsa_Dinoko), a featural script designed for Bantu phonologies (see the sample in `files/Ditema_Tsa_Dinoko_Syllabary_Sample.svg`); it is not yet encoded in Unicode, so Latin serves until then. Even Ditema marks prenasalization with a diacritic rather than dedicated letters, so the digraph conventions below carry over directly.

The prenasalized stops are written **mb, nd, nj, ng, mp, nt, nk** and count as single consonants; the nasal is always homorganic with the stop. Before the fricative s the nasal stays n, giving the cluster **ns** (*nsómba* “fish”). Since the lone velar nasal is ŋ, the digraph ng always means /ᵑɡ/.

The digraphs ch, sh, ny, ng can never be ambiguous: Kintu syllables are (N)C(G)V, so no other consonant clusters exist for the letter pairs to be misread as.

The letters c, q, x have no value of their own: c appears only inside ch, and q and x are held in reserve for loanwords.

## Vowels and tone

Five vowels, written as above; there is no length contrast, so vowels are never doubled. High tone is written with an acute, low tone with nothing: á é í ó ú against a e i o u — *muntu* “person”, *nyáma* “animal”.
