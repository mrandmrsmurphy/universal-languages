# Orthography

> Parent: [[Balkan]]

Balkan is written in the Greek alphabet plus the Cyrillic letter Б/б — needed because Greek Β/β stands for /v/. The result is a cross between Ancient and Modern Greek letter values, though iota as (only) an approximant is new. The language's name: Бαλκαν ('bal.kan).

## Consonants

| | Labial | Alveolar | Palatal | Velar |
| --- | --- | --- | --- | --- |
| Nasals | /m/ Μ/μ | /n/ Ν/ν | | |
| Voiceless plosives | /p/ Π/π | /t/ Τ/τ | | /k/ Κ/κ |
| Voiced plosives | /b/ Б/б | /d/ Δ/δ | | /g/ Γ/γ |
| Voiceless affricate | | /ts~tʃ~tɕ/ τσ | | |
| Voiced affricate | | /dz~dʒ~dʑ/ δζ | | |
| Voiceless fricatives | /f/ Φ/φ | /s~ʃ/ Σ/σ/ς | | /x~h/ Χ/χ |
| Voiced fricatives | /v~ʋ/ Β/β | /z~ʒ/ Ζ/ζ | | |
| Approximants | | /r~ɹ/ Ρ/ρ | /j/ Ι/ι | |
| Lateral | | /l~ɫ/ Λ/λ | | |

- τσ and δζ are digraphs for the two affricates.
- Sigma is written ς word-finally, σ elsewhere.
- Θ/θ is used only in the transcription of foreign words.
- Ξ/ξ = /ks/ and Ψ/ψ = /ps/.

Letter values blend the two Greek eras: modern η = /i/, β = /v/, φ = /f/, χ = /x/; ancient υ = /u/, γ = /g/, δ = /d/; and the novel ι = /j/.

## Vowels

| | Front | Mid | Back |
| --- | --- | --- | --- |
| High | /i/ Η/η | | /u/ Υ/υ |
| Mid | /e/ Ε/ε | /ə/ Ω/ω | /o~ɔ/ Ο/ο |
| Low | /a/ Α/α | | |

Omega is repurposed as schwa, the sixth vowel that unstressed reduction adds to the usual five.
