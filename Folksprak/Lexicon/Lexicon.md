# Lexicon

> Parent: [[Folksprak]] · Basic list: [[Folksprak/Swadesh]] · Rules: [[Folksprak/Word formation guidelines]] · Sounds: [[Folksprak/Phonology]] · Script: [[Folksprak/Orthography]]

Dictionary of Folksprak roots, one file per word, each re-evolved from its Proto-Germanic source (see [[Folksprak/Anthropology#Prolegomena]]). The file name and title are the runic spelling; the Latin romanization is a row in the entry. Verbs are entered in the infinitive (**+e**); everything else in its bare form.

## Entry format

Title is the runic spelling, followed by a table with these rows (omit a row that doesn't apply):

| Row | Content |
| --- | --- |
| Latin | Romanization per [[Folksprak/Orthography]] |
| IPA | Per [[Folksprak/Phonology]] |
| Part of speech | |
| Gloss | English meaning |
| Proto-Germanic | Source form |
| Composition | Parts of a compound, with glosses |
| Cognates | Reflexes in other Germanic languages |
| Etymology | Source chain for loanwords, in place of Proto-Germanic |
| Swadesh | № in [[Folksprak/Swadesh]], if any |
