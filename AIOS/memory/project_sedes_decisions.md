# SEDES decisions

**Why:** The user (Aquatiki, the author; no committee) settled these point by point, partly against a friend's design suggestions. Don't re-derive or revert them; the pages in `SEDES/` hold the facts, this file holds the reasoning and what is still open.

**How to apply:** Treat the points below as settled. The page set is `SEDES/SEDES.md` (hub) plus `SEDES/Anthropology`, `Phonology`, `Orthography`, `Morphosyntax`, `Swadesh`.

- SEDES decisions (user, 2026-10-23): SOV, AGGLUTINATIVE (changed from fusional after a friend's design review: the Esperanto model), nominative–accusative (marked nominative), no stress/tone, 2 genders, relative clause before the noun; foundation is the Horn of Africa sprachbund with Proto-Afroasiatic consulted; five vowels only (a e i o u — never ä; Geʿez first order = /a/); ejectives are pʼ tʼ čʼ kʼ; native name ቀርኒ (q'arnī); the abugida m row is መ ሜ ሚ ሞ ሙ. Sudan overlaps Middle Semitic and is not distinguished from South Sudan.
- SEDES design, continued (user, 2026-10-23): recognition-based vocabulary (a pseudo-historical proto-SEDES root is allowed where there is no clear winner); the user keeps 2 genders and obligatory marked-nominative case (-ni nominative, -na accusative) against a friend's suggestion of none; no verbal agreement (it would double-mark); converbs form subordinate clauses; adjectives follow the noun (mostly head-final otherwise); wide core list, to shrink later. The user is the author (Aquatiki); attribution to the friend is not needed in the pages. Pending: tense/aspect as affix vs particle, possessive affixes vs pronouns.
- SEDES conventions (user, 2026-10-23): coined SEDES forms in `SEDES/Swadesh.md` are links `[[Ge'ez spelling]]` to lexicon files not yet created (the user will start the lexicon later; file names will be the Ge'ez spelling, as with Folksprak runes and Interslavic Cyrillic). Case endings count as postpositions. Pronouns may drop the case ending when the role is obvious. Vowel-initial words begin with a glottal stop (/ʔ/, written with the አ series). First coined form: ani = [[አኒ]] ('I').
- Open as of 2026-10-23: no SEDES lexicon yet (the user will start it; first word *ani*, [[አኒ]]); Oromo column of `SEDES/Swadesh.md` is a linguistic transcription, not Qubee (user to decide); Somali item 196 "habban > habboon" kept as written; the SEDES local map is a Britannica-copyrighted Quora image to be replaced with a Commons map; SEDES's `Tigrinya` Swadesh forms were dropped from the table.
