# Dravindian decisions

Settled design for the Dravidian UL (notes received 2026-10-26).

## Settled

- Foundation: Proto-Dravidian; zone = South India / Sri Lanka. Sources: Tamil, Telugu, Kannada, Malayalam, Tulu, Gondi, and Proto-Dravidian reconstruction. Sister project to Neo-Sanskrit. Population ~230M.
- Name: 𑀩𑁆𑀭𑀸𑀳𑁆𑀫𑀻 (bra.mi). SOV, agglutinative (user decision — the infobox's "Fusional" was a template leftover), nominative–accusative.
- Script: Brāhmī. Long ē/ō are Brāhmī 𑀏/𑀑; short e/o are Old Tamil 𑁱/𑁲 (see Session 2026-11-02).
- Phonology: m n ɳ ɲ ŋ; p t ʈ tɕ~tʃ~c k; b d ɖ dʒ~ɟ g; fricatives f~v~ʋ, s~z, ʂ, ɕ, h; laterals l ɭ; approximants r ɻ j. Two NON-NATIVE series for Hindi/Sanskrit loans: aspirated (pʰ tʰ ʈʰ cʰ kʰ) and breathy (bʰ dʰ ɖʰ ɟʰ gʰ). Native stops contrast voiced/unvoiced only — no aspirated or creaky series.
- Vowels: five × short/long (i iː e eː a aː o oː u uː). NO phonemic nasal vowels (user decision 2026-10-26 — no major Dravidian language has them; nasality allophonic at most).
- Phonotactics: CVN maximum syllable; any consonant can geminate, and a geminate does not count as the previous syllable's coda.
- Morphosyntax categories settled (forms NOT yet coined): 8 cases, 3 genders, clusivity, T–V distinction, negation on the verb, polar-question marker on the verb.
- Roadmap stays 2 (phonology + orthography fixed; morphology categories chosen but no forms). Hub moved into Dravindian/ (root stub removed).

## Session 2026-11-02

- Anthropology page now has "Why separate from Neo-Sanskrit" (9 reasons: unrelated families, areal retroflexes, no native aspiration, no ergativity, agglutinative suffixing, clusivity/T–V, CVN syllables, vowels, universals test) and a tiered "Source languages" table (T1 Telugu/Tamil/Kannada/Malayalam; T2 Gondi/Tulu; T3 Kurukh/Brahui + small languages; Proto-Dravidian reference). The rationale is a reconstruction by Claude, not the user's original investigation notes — user to confirm/amend. Kurukh and Brahui proposed as northern-branch additions (not yet user-approved).
- Orthography fix: 𑁳/𑁰 were actually Old Tamil short-e sign and Old Tamil virama, not long-vowel signs. Now: 𑀏/𑀑 = long ēː/ōː (Tamil-Brāhmī), short e/o = 𑁱/𑁲 (signs 𑁳/𑁴); ɻ = 𑀵 (Old Tamil LLLA), not 𑀶 (RRA, ṟ). Vowel-sign table added.
- Rulings (user, same session): add diphthongs /ai/ /au/ (𑀐 𑀒, signs 𑁃 𑁅; one nucleus, so CVN holds). No alveolar ṟ/ṉ — only Tamil/Malayalam have it. Voiced/voiceless contrast in plosives only is kept; source is WALS 4A (all six source languages are "in plosives alone"), so the stop/fricative asymmetry is evidence-based, not loan-driven. Relative clause = ante (fixed in Anthropology, Language Comparisons, build script). Stress = first syllable (fixed; was R by mistake). Language name equal to script name (Brāhmī) agreed to be a problem — new name still to be chosen.
