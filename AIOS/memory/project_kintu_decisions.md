# Kintu decisions

- Foundation (user, 2026-10-27): Proto-Bantu WITH MODIFICATIONS — PB taken as already leaning in the modern directions (e.g. Swahili was always popular). The daughter languages are a recognition check, not a vote.
- Zone: STRICTLY Bantu — no Khoisan, Cushitic, Nilotic or West African languages; border regions (Somali-coast Bantu, Comorian, Cameroon/Gabon zones A/B) are kept well clear because Swahili is overpowered and would underweight its neighbours. Source languages follow Guthrie groupings: East (Swahili, Gikuyu, Kinyarwanda, Kirundi, Luganda), Central (Lingala, Tshiluba, Kikongo, Bemba), Southern (Shona, Nyanja, Zulu, Xhosa, Sotho, Tswana), Southwest (Umbundu, Herero). User: the list may be larger than feasible; trim as needed.
- Files: `Kintu/` with Kintu (hub), Anthropology, Phonology, Morphosyntax, split from the old root stub (no content lost). Anthropology prose drafted from general knowledge — user review pending.
- Zones A/B OUT; weighting by where speakers are now (PB homeland north, centre of gravity south). SETTLED 2026-10-27: FIVE vowels (i e a o u; seven too hard for five-vowel speakers), penultimate stress, perfective/imperfective Yes, two tones (only high marked), no definite article. Open: no Swadesh/Lexicon, no script work (Ditema not in Unicode).
- Orthography settled 2026-10-31: interim Latin, Ditema long-term (still unencoded in Unicode; even Ditema marks prenasalization with a circle diacritic, not dedicated letters). Digraphs ch /tʃ/, sh /ʃ/, ny /ɲ/; lone velar nasal spelled with its own letter ŋ (user types ŋ directly — the ng' convention was proposed and REJECTED), ng reserved for /ᵑɡ/; j /dʒ/ with y for /j/; prenasalized stops mb nd nj ng as unit phonemes; no digraph collisions possible because syllables are (N)C(G)V; c q x unassigned (q/x loan reserve); high tone = acute.
- PB sound changes settled 2026-10-31, ORDERED (user correction: the changes must apply in historical order, since the different PB vowels conditioned different consonant changes): 1) spirantization before the second-degree/super-close vowels *ɪ *ʊ (*p→f, *b→v, *t→s, *d→z, *k→s) — sources: Kingston 2008, Bostoen 2008 "Bantu Spirantization", Faytak & Merrill; 2) palatalization after first-degree *i (southern "PI-effects": n→ɲ, s→ʃ-type); 3) *c→s (eastern reflex); 4) *d→d initial/post-nasal, l intervocalic; 5) merger *ɪ→i, *ʊ→u (7→5) — ordered last so the close-vowel conditioning is still in force; 6) vowel length dropped; 7) loans add h, r. Tone H/L preserved, only H written.
- Verb morphology SETTLED 2026-10-31, replacing the provisional sketch entirely (user set the categories, forms proposed by me and accepted): template NEG–SUBJ–TAM–OBJ–ROOT–EXT–FV. Negation = invariant pre-initial **ka-** (user's own pick over ha-/te options; Comorian pre-initial ka- is the closest model; freed from its old remote-past job). Tense: non-past Ø, past li-, future ta-. Aspect: progressive na-, habitual sa-, anterior me-; aspect stacks after tense, no fused forms. Mood in the final vowel: -a indicative, -e subjunctive/jussive; imperative = bare stem + -a, plural -ni. Person markers subj ni u a tu mu ba, obj -ni- -ku- -mu- -tu- -ni- -ba-. Seven extensions = the PB set with sound changes applied: causative -is- (<*-ici-), applicative -il- (<*-id-), reciprocal -an-, passive -w- (<*-u-), potential/stative -ik-, reversive tr. -ul- (<*-ud-), reversive intr. -uk-. Invariant forms, no vowel harmony. Noun-class examples fixed in the same pass (muti/miti "tree(s)" = PB *-tí, buntu "humanity" for class 14, ninyama for class 10).
- Tone settled 2026-10-31 (user picked option 1 of a 3-part proposal): tone is LEXICAL and lives on roots only — each root specified H or L, noun stems one H syllable at most; ALL affixes (class prefixes, ka-, SUBJ/OBJ markers, TAM, extensions, FV) are toneless, surface low. Consequence written into the page: since all grammar is affixal, tone never carries grammar. Tone marking policy settled 2026-10-31 (user): no H/L phoneme-pair framing — high vowels are simply written á é í ó ú, low a e i o u, acute marked EVERYWHERE including running text (no "optional in fluent text" rule). What remains unruled: whether any tone rules (spread/shift) exist — the standing assumption is none.
- Lexicon begun 2026-10-31: `Kintu/Lexicon/` with Lexicon.md index + 7 seed entries (muntu, muti, kitu, nyáma, buntu, njila, bóna). Conventions (Folksprak-adapted): one file per word; FILENAME = plain Latin WITHOUT tone marks, title = tone-marked form; nouns entered singular with Class row (class pair + plural form); verbs entered as stem + -a (infinitive is regular ku- + stem); rows IPA / POS / Gloss / Class / Proto-Bantu / Composition / Cognates / Etymology / Swadesh №. Tone assignments so far are first-pass (nyáma, bóna marked H) — VERIFY against BLR3 tone columns as Swadesh coinage proceeds. Fixes made in the same pass: kunzila → kunjila (nz is not a Kintu phoneme; class-9/17 n + j = nj); Morphosyntax verb examples tone-marked (bón- is H).
- Lexicon source identified 2026-10-31: BLR3 (Bastin, Coupez, Schadeberg et al., ~10,000 PB reconstructions, searchable online + standalone app) — https://www.africamuseum.be/en/research/discover/human_sciences/culture_society/blr — the raw material for Swadesh coinage under PB-with-modifications.
