# Kintu decisions

- Foundation (user, 2026-10-27): Proto-Bantu WITH MODIFICATIONS — PB taken as already leaning in the modern directions (e.g. Swahili was always popular). The daughter languages are a recognition check, not a vote.
- Zone: STRICTLY Bantu — no Khoisan, Cushitic, Nilotic or West African languages; border regions (Somali-coast Bantu, Comorian, Cameroon/Gabon zones A/B) are kept well clear because Swahili is overpowered and would underweight its neighbours. Source languages follow Guthrie groupings: East (Swahili, Gikuyu, Kinyarwanda, Kirundi, Luganda), Central (Lingala, Tshiluba, Kikongo, Bemba), Southern (Shona, Nyanja, Zulu, Xhosa, Sotho, Tswana), Southwest (Umbundu, Herero). User: the list may be larger than feasible; trim as needed.
- Files: `Kintu/` with Kintu (hub), Anthropology, Phonology, Morphosyntax, split from the old root stub (no content lost). Anthropology prose drafted from general knowledge — user review pending.
- Swadesh working check set settled 2026-11-01: SIX columns — Swahili, Kinyarwanda (stands in for Kirundi), Lingala, Zulu, Shona, Umbundu. Rationale: all four regions, biggest L2 networks, two 7V languages (Lingala, Umbundu) kept in as merger/spirantization checks. User picked "take all six" over 5-language speaker-max and region-max variants. Planned Kintu Swadesh page columns: №, English, PB (BLR3), the six daughters, Kintu LAST (per the Swadesh page style memory).
- Zones A/B OUT; weighting by where speakers are now (PB homeland north, centre of gravity south). SETTLED 2026-10-27: FIVE vowels (i e a o u; seven too hard for five-vowel speakers), penultimate stress, perfective/imperfective Yes, two tones (only high marked), no definite article. Open: no Swadesh/Lexicon, no script work (Ditema not in Unicode).
- Orthography settled 2026-10-31: interim Latin, Ditema long-term (still unencoded in Unicode; even Ditema marks prenasalization with a circle diacritic, not dedicated letters). Digraphs ch /tʃ/, sh /ʃ/, ny /ɲ/; lone velar nasal spelled with its own letter ŋ (user types ŋ directly — the ng' convention was proposed and REJECTED), ng reserved for /ᵑɡ/; j /dʒ/ with y for /j/; prenasalized stops mb nd nj ng as unit phonemes; no digraph collisions possible because syllables are (N)C(G)V; c q x unassigned (q/x loan reserve); high tone = acute.
- PB sound changes settled 2026-10-31, ORDERED (user correction: the changes must apply in historical order, since the different PB vowels conditioned different consonant changes): 1) PARTIAL spirantization (user ruling 2026-11-01, replacing the full-spirantization first draft): only voiceless *p→f and *k→s, before second-degree *ɪ ONLY (not *ʊ), root-internal; voiced stops, *t, prenasalized clusters and grammatical prefixes exempt. Motivation: full spirantization would have wrecked muti (-t before ɪ), -tatu, -kúlu, kintu (class-7 prefix); the partial rule costs exactly one retrofit, -kúpi → **-kúfi** (p before ɪ́; matches Kinyarwanda -gufi). f is now native; v z join r h as LOAN phonemes; 2) palatalization after first-degree *i (southern "PI-effects": n→ɲ, s→ʃ-type); 3) *c→s (eastern reflex); 4) *d→d initial/post-nasal, l intervocalic; 5) merger *ɪ→i, *ʊ→u (7→5) — ordered last so the close-vowel conditioning is still in force; 6) vowel length dropped; 7) loans add h, r. Tone H/L preserved, only H written.
- Verb morphology SETTLED 2026-10-31, replacing the provisional sketch entirely (user set the categories, forms proposed by me and accepted): template NEG–SUBJ–TAM–OBJ–ROOT–EXT–FV. Negation = invariant pre-initial **ka-** (user's own pick over ha-/te options; Comorian pre-initial ka- is the closest model; freed from its old remote-past job). Tense: non-past Ø, past li-, future ta-. Aspect: progressive na-, habitual sa-, anterior me-; aspect stacks after tense, no fused forms. Mood in the final vowel: -a indicative, -e subjunctive/jussive; imperative = bare stem + -a, plural -ni. Person markers subj ni u a tu mu ba, obj -ni- -ku- -mu- -tu- -ni- -ba-. Seven extensions = the PB set with sound changes applied: causative -is- (<*-ici-), applicative -il- (<*-id-), reciprocal -an-, passive -w- (<*-u-), potential/stative -ik-, reversive tr. -ul- (<*-ud-), reversive intr. -uk-. Invariant forms, no vowel harmony. Noun-class examples fixed in the same pass (muti/miti "tree(s)" = PB *-tí, buntu "humanity" for class 14, ninyama for class 10).
- Tone settled 2026-10-31 (user picked option 1 of a 3-part proposal): tone is LEXICAL and lives on roots only — each root specified H or L, noun stems one H syllable at most; ALL affixes (class prefixes, ka-, SUBJ/OBJ markers, TAM, extensions, FV) are toneless, surface low. Consequence written into the page: since all grammar is affixal, tone never carries grammar. Tone marking policy settled 2026-10-31 (user): no H/L phoneme-pair framing — high vowels are simply written á é í ó ú, low a e i o u, acute marked EVERYWHERE including running text (no "optional in fluent text" rule). What remains unruled: whether any tone rules (spread/shift) exist — the standing assumption is none.
- Lexicon begun 2026-10-31: `Kintu/Lexicon/` with Lexicon.md index + 7 seed entries (muntu, muti, kitu, nyáma, buntu, njila, bóna). Conventions (Folksprak-adapted): one file per word; FILENAME = the TONE-MARKED spelling (user correction: tone is phonemic on roots, so acute-vs-plain pairs could collide — no unmarked filenames); nouns entered singular with Class row (class pair + plural form); verbs entered as stem + -a (infinitive is regular ku- + stem); rows IPA / POS / Gloss / Class / Root / Proto-Bantu / Composition / Cognates / Etymology / Swadesh №. `Kintu/Roots/` (Roots.md index + one file per root: ntu, ti, tu, nyáma, jila, bón) documents the tone-bearing roots themselves, parallel to Middle Semitic's root pages; each word entry has a Root row linking there, each root entry lists its derived Words. Tone assignments so far are first-pass (nyáma, bóna marked H) — VERIFY against BLR3 tone columns as Swadesh coinage proceeds. Fixes made in the same pass: kunzila → kunjila (nz is not a Kintu phoneme; class-9/17 n + j = nj); Morphosyntax verb examples tone-marked (bón- is H).
- Max-regularity derivation pass 2026-10-31 (user principle: "whenever we make a root, ask what are all the possible words I can create from it"). Three outcomes: (1) "thing" re-derived as kintu/bintu from -ntu (PB *kɪntʊ IS class-7 *-ntʊ; Luganda ekintu, Kikongo kintu, Zulu into; Swahili kitu dropped the nasal) — kitu.md and the -tu root page deleted, -tu was never a separate root. (2) PB nominalizers settled as productive: agentive -i (cl 1/2, mubóni "witness") and deverbal -o (cl 3/4 instance/result, cl 14 abstract: mubóno "sight", bubóno "vision"). (3) Voiceless prenasalized stops added to the inventory (mp nt nk) — muntu/kintu already contained nt. Rule written into Lexicon.md: run every root through the full machinery (class mobility, 7 extensions, -i, -o), coin every NATURAL result, flag unattested ones "plausible extension, not directly attested" (so far: buti "forest", bunyáma "animality"). Lexicon now 13 entries; Roots 5 pages (ntu, ti, nyáma, jila, bón).
- Swadesh batch 1 coined 2026-11-01 (№1–21, user approved proposal unchanged): pronouns ini uwe eye itu imu ibo (vowel + person-stem pattern, PB *nìnè/*gùwè for 1–2, LOW tone — initial proposal wrongly had acutes; only roots carry tone); demonstratives -no (proximal, attested in hano/pano 'here') / -dyá (distal, PB *dɪ́á, 8 zones) + class concord (unu, udyá), locatives kunu/kudyá; nani 'who', kí 'what' (PB *í cl 7, 10 zones), kwí 'where' (PB *íí cl 16 → 17), lini 'when', njani 'how'; ka 'not/no' (the ka- prefix free, LOW); adjective stems -onse 'all' (PB *-once, applies c→s; tone pending), -íngi 'many' (PB *ŋɪ́jingɪ́), -mwe 'some' († weakest in batch), -ké 'few' (PB *kéè), -ndíngi 'other' (PB *ndɪ́ŋgɪ́). `Kintu/Swadesh.md` created with all 207 rows (№22+ uncoined); build_swadesh.py registered Kintu (pages + ORDER last + status row + intro) — root Swadesh.md now has a Kintu column.
