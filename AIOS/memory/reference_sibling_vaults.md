# Sibling vaults and external sources

**Why:** Some work referenced from this vault lives outside it; a future session should know where to look before assuming content is missing or re-deriving it.

**How to apply:**

- **The danayo vault** — `/Users/robertmarshallmurphy/Documents/danayo`, a sibling Obsidian vault (the AIOS memory-system convention itself comes from there). Dan'a'yo is in fact **the furthest along of all fifteen ULs** by a wide margin. Scale (verified against its `AIOS/vault-structure.md` and `git ls-files`, 2026-10-24): **3,370 character pages** (characters only, never words; `X (char).md` = a same-name word exists), **6,529 word pages** (mostly compounds, ~2:1 over characters), **902 syllable pages**, **241 chengyu** (citations verified against sources) — all four folders fully "perfected," no backlog. Plus a 16-chapter grammar (`grammar/単亜語之文法書.md`; English mirrors for ch. 1–5, pragmatics skeletal), a 64-page lexipedia, lookup trees (SKIP, radicals, strokes, Classical Chinese phonology, HSK/Jōyō/Korean levels), classical-text translations (fragmentary), an embryonic Bible project, and 3 of 20 planned lessons. It has its own AIOS (memory, checklists, skills, 7 Python linters + `build_grade.py` in `AIOS/scripts/`). Its own docs rate it ~85% sufficient for reference use, ~40% for learners; lessons are the open frontier. Counts drift — read `danayo/AIOS/facts.yaml` (the reportage-protocol front door), not remembered numbers; its own AGENTS.md prescribes `git ls-files` over `find` (the vault is iCloud-synced and a plain walk can hang). Dan'a'yo's complete comparative Swadesh lives there at `lexipedia/Swadesh.md` (Old Chinese, Mandarin, Cantonese, Japanese, Korean, Vietnamese, Dan'a'yo); the root `Swadesh.md` here is the cross-UL comparative hub (filled 2026-10-26) and imports from it. Check the danayo vault before expanding any local Dan'a'yo material. Dan'a'yo's SCRIPT is Shinjitai + Bopomofo, with Bopomofo as ruby wherever possible (user ruling 2026-10-26); the 諺文/Hangul field on its word pages is a transcription convention for readers, NOT the language's script — don't present Hangul as the script on this vault's pages.

- **Folksprak sources** — inventoried 2026-10-24. Accessible: **folksprak.org** fully fetchable — the DokuWiki (`/wiki/doku.php`, raw HTML enumerates pages even though the index is JS) is a proposal-comparison meta-wiki (~34 main pages: conjugation, declension, pronouns, correlatives, adpositions, phonology_and_orthography, runes, words, guidelines_for_word_formation, ~7 sample texts incl. the Great Dictator speech; plus 458 `concepts:*` lexical-concept pages with candidate forms across 9 Germanic languages + PGmc, and 11 `references:*` proposal/dialect pages); **`folksprak.org/draft/draft.html`** is the nearest thing to a normative spec (phonology/orthography table with runes, PGmc sound correspondences, pronouns, conjugation -e/-end/-et, hav-perfect, skal/vil future, plural -er, genitive -(e)s, articles en/de — but correlatives/adpositions/modals/declension marked "proposal yet"); the **Munin dictionary** (`?target=dictionary`) is ~456 entries inlined as JSON in HTML. The **two Google Drive files download without auth**: `0Bx0T9Dxrods1dVVqaXVyOVZmSTg` = David Parke's English→Folksprak dictionary PDF (107 pp, 2011); `0Bx0T9Dxrods1em9yRGh6d1BacEU` = Parke's Folksprak→English "Wordbok" (Babylon-glossary HTML, ~5,900 entries, 2010) — the largest Folksprak lexicons extant. Blocked/absent: Linguifex (Anubis; hosts the variant dialects Sprak/Middelsprake/Frenkisch — recoverable only via web.archive.org), Reddit r/folksprak (403), Omniglot (403), Yahoo Groups polls (dead with Yahoo; outcomes survive in the wiki's "Decisions made so far"). Wikipedia's "Pan-Germanic language" article is history-only. No Folksprak Swadesh list exists anywhere outside this vault. Remember the wiki has third-party errors; the user (Aquatiki) is the project's whole committee.
