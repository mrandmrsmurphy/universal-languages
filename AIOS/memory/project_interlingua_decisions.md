# Interlingua decisions and sources

**Why:** Interlingua is an extant language being documented, not invented (roadmap score 9); decisions here are about the vault's framing and boundaries, not about changing the language.

**How to apply:**

- Boundaries (user, 2026-10-24): the zone is the Romance world. **Romanian is shared with Balkan** — genetically Romance, but a core Balkan sprachbund member; the overlap is by design, like Sudan overlapping Middle Semitic. English is an IALA control language and shaped the design (e.g. no noun gender), but is **not** part of the zone Interlingua serves.
- Zoning inside the Anglosphere (user, 2026-10-24): the English-speaking world is Folksprak by default — South Africa definitely so (Folksprak absorbs Afrikaans) — but largely Hispanic parts of America lean Interlingua. Zones within the English-speaking world are a planned feature, not an anomaly.
- The language itself is IALA's 1951 product (Gode & Blair, Grammar + Interlingua–English Dictionary); ISO 639-1 `ia`. User's stance: "an excellent regional compromise; preference would have been to keep two genders, but the project stands as-is" — document, don't reform.
- Gender rationale (for the Anthropology/Morphosyntax pages): IALA's rule was to omit any feature absent from a primary control language (English kills gender/agreement, French kills progressives); and the Romance languages disagree on gender assignment anyway (el mar m. / la mer f. / il mare m.), so there was no common system to inherit.
- Open: the hub infobox says "Foundation: Proto-Romance" — real Interlingua is extracted from the international vocabulary of its control languages, not derived from Proto-Romance. Flagged to the user; not yet settled whether to correct the framing.
- Reachable documentation: Wikipedia (full article + "Interlingua grammar" article, incl. phonology/orthography), interlingua.com (UMI, official), Wiktionary (Interlingua entries), Wikibooks transcription of the Gode & Blair Grammar (§1-16 orthography used for `Interlingua/Orthography.md`). The Grammar's §15 collateral orthography is documented on the Orthography page.
- Lexicon conventions (set up 2026-10-24): `Interlingua/Lexicon/`, one file per word, lowercase Latin filenames; rows = Part of speech (verbs, cited as infinitives), Gloss, Latin, Compare (Portuguese; Spanish; French; Italian), Swadesh №. Built from the user's own Swadesh table (Romanian column and parenthetical remarks dropped at the user's request); 219 entries from the 207 rows. Every Swadesh form is a lexicon link, per the other ULs' convention.
- The Interlingua–English Dictionary is canonical (user, 2026-10-24): when the user's own tables or other sources conflict with the IED, follow the IED. Settled accordingly: №187 rotten = putride, №168 ash = cinere (both now on the Swadesh page and renamed in the lexicon).
- The user's Swadesh table had a duplicate №110 (kill/hunt); hunt renumbered to the standard 112. Fixes applied while transcribing: №8 "that" illa → ille (typo; illa = she), №18 Latin plmultī → plūrēs, №90 Portuguese Coração → coração.
