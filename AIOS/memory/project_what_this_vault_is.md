# What this vault is

This vault documents the **Universal Languages (UL)** project: fifteen regional auxiliary languages, each built on a proto-language or sprachbund of its region (Folksprak ← Proto-Germanic, Middle Semitic ← Proto-Semitic, Neo-Sanskrit ← Sanskrit, Dan'a'yo ← Classical Chinese, etc.), intended to let people within a linguistic region communicate without defaulting to a colonial/global language. See `Universal Languages.md` for the full pitch and the table of the fifteen. Two extra projects outside the core fifteen are also tracked: Samboka and Caucas.

**Why:** The premise is spread across `Universal Languages.md` and implied by the per-language stubs; a future session shouldn't have to reconstruct "what is this vault for" from 20+ pages. This is the one-paragraph version.

**How to apply:** Treat `Universal Languages.md` as the hub. A language's hub page lives inside its subtree folder once the language has real work done (`Folksprak/Folksprak.md`, … — moved in from the root 2026-10-25 to keep the root surveyable); stubs without subtrees stay at the vault root, as do hub pages for languages with their own vaults (`Dan'a'yo.md`, `Middle Semitic.md`). Subtrees use the standard page set — Anthropology, Phonology, Orthography, Morphophonology, Morphosyntax, Swadesh (Folksprak adds "Word formation guidelines"). `Language Comparisons.md` is the cross-UL feature matrix (WALS-oriented); `Swadesh.md` at root is the cross-UL comparative hub, built by `AIOS/scripts/build_swadesh.py` (see [[reference-sibling-vaults]]). When adding a new language or growing a stub into a subtree, follow the existing hub-page + standard-subpages pattern, and update both `Language Comparisons.md` and `AIOS/site-map.md`.

- "Dravindian" (the Dravidian UL) is the vault's own neologism, not a misspelling — never "correct" it to Dravidian. Flag images live in `files/flags/` (one per core UL; filenames kept as downloaded, e.g. `Drivindian_flag.svg`, `Flag_of_Folkspraak.svg`) and are embedded in each hub page's infobox and in the `Universal Languages.md` table.
- Graduation rule (user, 2026-10-24): once a UL crosses into roadmap-milestone-7 territory (working lexicon, 1,000+ words), or outgrows the shared format, it gets its own vault so as not to clutter this one — Dan'a'yo lives at `/Users/robertmarshallmurphy/Documents/danayo`, Middle Semitic at `/Users/robertmarshallmurphy/Documents/middle-semitic`. Until then each language is incubated here with the standard subtree. Scores and milestones are tracked in `Development Roadmap.md`.
- Family structure (user, 2026-10-29): this vault is the **parent node** of the Universal Languages project; Dan'a'yo is the project's **flagship language** (first and furthest along, the model the others follow); middle-semitic is the second sibling vault. Inter-vault communication is uncommon but must be painless and consistently formatted: the reportage protocol (each vault self-reports via `AIOS/facts.yaml`, regenerated by `AIOS/scripts/build_facts.py`; outside agents read it, never prose counts), and requests between vaults travel as dated note files placed in the target vault's `AIOS/` folder, handed over by the user (see [[reference-sibling-vaults]]).
- Samboka's flag is `files/flags/finno-ugric.png` and Caucas's is `files/flags/Caucasus.svg` (added 2026-10-23); neither is in the `Universal Languages.md` table, since they are outside the core fifteen.
- Script principle (user, 2026-10-25): the long-term plan is for every UL to have its own separate script; Latin is only ever a TEMPORARY acceptance (as with Interslavic). So Ortatürk's long-term script is Armenian even though its upstream materials are Latin.
- The user is colour-blind (confuses reds/oranges/greens; Balkan and Zens looked alike). For any chart or map, check colours with deuteranopia/protanopia simulation, keep adjacent regions' colours apart by lightness as well as hue, and avoid near-white fills. Map colour scheme used in `files/Universal_Language_cb.png`: Folksprak #cc3333, Interlingua #1d91c0, Balkan #1f6f6b, Interslavic #85c97e, Dan'a'yo #ffffb3, Ortatürk #9970ab, Middle Semitic #cf597e, Kintu #00441b, Guosa #e6ab02, SEDES #4d004b, Zens #b3de69, Neo-Sanskrit #084081, MSEAL #f28e2b, Indo-Malay #8c510a, Dravindian #7b6fd6. Legend keeps "S.E.D.E.S." and "M.S.E.A.L." (they are acronyms: Somalia, Eritrea, Djibouti, Ethiopia, Sudan; the MSEAL acronym is Mainland Southeast Asian Languages).
- Markdown tables: inside a table cell, escape the pipe in image embeds and wikilink aliases (`![[flag.svg\|60]]`, `[[Page\|alias]]`) or the cell splits and the image won't show. Obsidian may auto-pad tables, which also breaks unescaped embeds — and it breaks scripts that match exact padded strings, so scripts editing table cells must split rows on unescaped pipes and match stripped cell content, then verify uniform cell counts after writing.
