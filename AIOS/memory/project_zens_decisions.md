# Zens decisions

Settled design for the pan-Iranian UL (notes received 2026-10-25).

## Settled

- Foundation: Proto-Iranian; zone = Greater Persia / the Persosphere (Iran, Afghanistan, parts of Pakistan, Kurdistan, western Central Asia). Population ~175M (updated from the stub's 200M per the user's notes; Universal Languages table updated). Membership covers the ENTIRE Iranian branch — including the Caucasus Iranian languages Ossetian, Tat, Talysh, which are shared with Caucas as areal contributors there (user-confirmed 2026-10-26, same precedent as Romanian/Interlingua/Balkan and Turkic/Ortatürk/Caucas).
- Name: 𐬰𐬈𐬥𐬯 zens.
- Script: Old Avestan, RIGHT-TO-LEFT. Other Avestan letters allowed for etymological spelling of foreign words.
- Phonology: m n ŋ; p t tʃ k~q (ʔ marginal); b d dʒ g~ɢ; f s ʃ x~χ h; v z ʒ ɣ~ʁ; r~ɾ; w l j. Velar~uvular pairs span the Persian-vs-Pashto realization split. Six vowels: i u e o æ~a ɒ (the Persian low pair kept).
- Morphosyntax: SOV, agglutinative. TRIPARTITE alignment: nominative ø (intransitive subject), accusative -ra, ergative -(y)a. Tense-aspect: ø present/imperfect, -a past, -ro future, -na progressive, -da perfect. Evidentials: ø direct, lo hearsay, me inferential. Reduplication by word class: noun = scattered plurality, adjective = intensive, adverb = distributive, verb (partial) = habitual/repetitive.
- Roadmap score: 3 (phonology + core morphology documented).
