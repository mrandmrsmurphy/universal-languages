Qinghai (user, 2026-10-27): a possible sprachbund UL, even smaller in usage than Caucas — an "(dis)honorable mention". Source languages given: Wutun, Amdo Tibetan, Mangghuer, Mongghul, Bonan, Dongxiang, Salar, Western Yugur.

**Why:** the user mentioned it as a far-long-tail idea, to be recorded but not built out.
**How to apply:** it lives on the single root page `Qinghai.md` (same treatment as Caucas: no folder, lowest priority). No design yet. It is not in `Language Comparisons.md`; the family labels on the page are from general knowledge, not user-confirmed.

Shared features (user, 2026-10-27), recorded on `Qinghai.md`: definitely SOV; solidly postpositional and suffixing; no person/number marking on the verb; case, notably a merged accusative/dative; non-finite/converb constructions; plain vs. aspirated stop contrast; no tone; not high-complexity phonotactics; dative possessor construction. Still open: script, full phonology, case inventory, grammar.

Script (user, 2026-10-27): ʼPhags-pa — "it would be awesome". Thirteenth-century Tibetan-derived script made for Mongolic, so it suits a Tibetic/Mongolic/Turkic area; it is in Unicode (U+A840–A877). No letter assignments yet.

Phonology research (2026-10-27, scratch only, not on the page): PHOIBLE+WALS consonant survey. Amdo Tibetan 43–53 consonants; Bonan 25, Dongxiang 28, East Yugur 28, Salar 31; Wutun/Mongghul/Western Yugur not in PHOIBLE, Mangghuer only in WALS. Aspirated/plain pairs everywhere; true voiced stops only clearly in Amdo (and Mangghuer's b d g per WALS); Mongolic/Turkic "b d g" are the plain/lenis series. Open question put to the user: two-way plain/aspirated (voicing allophonic) vs three-way p/b/pʰ.

Consonant design target (user adopted, 2026-10-27), recorded on `Qinghai.md` under "Phonology target": plain+aspirated stops at p t k q; ts and tʃ each plain/aspirated; fricatives s ʃ x~χ h f; nasals m n ŋ; l r j w. Plain vs. aspirated is the only laryngeal contrast (no voiced series). The user thinks ʼPhags-pa can write all of it. Qinghai stays a ONE-PAGE language. Still open: retroflexes, prenasalised stops, vowels, ʼPhags-pa letter assignments, case inventory, grammar.
