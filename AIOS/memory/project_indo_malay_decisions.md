# Indo-Malay decisions

Settled design for the Maritime Southeast Asian UL (first notes received 2026-10-25).

## Settled

- Foundation: Proto-Malayo-Polynesian; zone is Maritime Southeast Asia; ~380M speakers.
- Script: Lontara (Bugis-Makassar script), already anticipated by the hub stub (sample ᨒᨚᨈᨑ). Glyph assignments follow authentic Lontara values — corrected from the user's draft, which had ᨍ for both ŋ and j: ŋ = ᨂ (nga), j = ᨐ (ya). (ᨍ is ja in real Lontara.)
- Phonology: small inventory — stops p t k ʔ b d g, nasals m n ɲ ŋ, liquids l r, glides w j, fricatives s ɕ~ʃ h. Six vowels: i e a o u + ə/ø. Syllables V, CV, CVN — nasal codas only. Palatals ɲ (ny) and ɕ (sy) added 2026-10-25 to account for the pronoun forms (etymological: sy < PMP *Su, s < *s).
- ᨛ triple duty: writes ə/ø, and serves as virama, glottal-stop marker, and cluster indicator.
- Pronouns: clusivity (incl/excl "we"), three-way number (sg/du/pl), informal vs. formal register, human/non-human 3rd person. Forms: 1excl ikia/ikinya/nimi, formal ikilun/ikilu/nipienimi; 1incl —/ikisyu/tieta, formal —/ikipien/nipienieta; 2 nisyu/nirua/nalian, formal nipien/nipienrua/nipienlian; 3 ninya/raua/sida, formal liu/liliu/liliu; 3nonhuman niya/nieya/nieya. Recurring elements: dual rua (< *duha, Oceanic-style r), politeness pien, reduplication in formal plurals. 3rd formal and 3rd non-human do not distinguish dual from plural.
- Romanization: acute accents in the original pronoun notes were not distinct vowels — é = plain e (user, 2026-10-25); nírua/ráua normalized to nirua/raua on the same logic (if they were stress marks, a stress rule can be recorded later). ń/ś confirmed as ny /ɲ/ and sy /ɕ/.
- Etymologies (recorded on Indo-Malay/Morphosyntax): syu < PMP *Su, sida < *siDa, nya < Malay -nya, ya < *ia, tieta < *kita, nimi < *kami, iki- contains *aku, nalian < kalian, liu < beliau, lun < Old Javanese ulun; pien's source unclear (possibly coined).
- Uniting features on the hub: clusivity, politeness on pronouns, dual number, reduplication.

- Lexicon (planned, per user 2026-10-25): one file per word with Lontara filenames under `Indo-Malay/Lexicon/`, following the Folksprak/Interslavic/Middle Semitic pattern; table links use `[[Indo-Malay/Lexicon/SCRIPT\|SCRIPT roman]]`. The pronoun table on Morphosyntax already links to 24 such (not yet created) pages — do not create word pages until asked.
- Spelling rules attested from the pronoun transliteration: vowel-initial syllables and hiatus take the ᨕ carrier; nasal codas take nasal letter + ᨛ virama. RESOLVED 2026-10-25 (user): pien = pi.ʔen and lian = li.ʔan — a hiatus ᨕ onseting a nasal-final syllable is a PRONOUNCED glottal stop, making ʔen/ʔan legal CVN syllables; VN syllables remain outside the canon.

- Question words (proposed by the user's friend, checked against the phonology, adopted 2026-10-25 with two respellings): apa 'what' (< apa), ngukiniu 'why-reason' (ngu- < mengapa + kiniu < kenapa), tukiniu 'why-purpose' (tu- < untuk + kiniu; friend's tukkiniu degeminated — k not a legal coda), siniu 'who' (< siapa), niesin 'which', dia/kie/nure + mina 'where/whither/whence' (< di/ke/dari mana; nure drops dari's d), nianu 'when' (contains anu 'whatchamacallit'), kuja 'how' (< bagaimana, cf. Sundanese kumaha), niruniu 'how much/many' (friend's nirniu + inserted u — r not a legal coda). Recurring -niu element is a potential question-formative morpheme. All linked on Morphosyntax; no word pages created yet.
