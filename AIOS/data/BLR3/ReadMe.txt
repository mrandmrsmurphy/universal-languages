In the database menu, you will find a history of the Bantu Lexical Reconstructions (BLR). After a preliminary test version, used for teaching at Leiden University, this edition is the first public version of BLR3. It has been released in 2003.

The CD works both with Mac (Os X) and Windows. The appropriate content will be displayed according to your platform.
These files  are also available for download at:

http://linguistics.africamuseum.be

The font BantuPhon is included (the files BaPB_.TTF and BaPR_.TTF). Install it in your computer.
Copy the content to your hard disk to be able to run the BLR without the CD.
