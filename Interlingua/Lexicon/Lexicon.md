# Lexicon

> Parent: [[Interlingua]] · Basic list: [[Interlingua/Swadesh]] · Sounds: [[Interlingua/Phonology]] · Script: [[Interlingua/Orthography]]

Dictionary of Interlingua words, one file per word. Interlingua is a finished IALA language (1951), documented here rather than invented: entries are keyed to the Interlingua–English Dictionary, with the control-language cognates as evidence. File names are the Interlingua spelling, lowercase.

## Entry format

| Row | Content |
| --- | --- |
| Part of speech | When useful (verbs cited as infinitives) |
| Gloss | English meaning |
| Latin | Classical source |
| Compare | Portuguese, Spanish, French, Italian forms |
| Swadesh | № in [[Interlingua/Swadesh]], if any |
