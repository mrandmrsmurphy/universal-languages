# Orthography

> Parent: [[Indo-Malay]]

Indo-Malay is written in Lontara (the Bugis-Makassar script). The glyph assignments follow authentic Lontara values: /ŋ/ is ᨂ (nga) and /j/ is ᨐ (ya).

## Consonants

| | Labial | Alveolar | Palatal | Velar | Glottal |
| --- | --- | --- | --- | --- | --- |
| Voiceless stops | p ᨄ | t ᨈ | | k ᨀ | ʔ ᨕ |
| Voiced stops | b ᨅ | d ᨉ | | g ᨁ | |
| Nasals | m ᨆ | n ᨊ | ɲ ᨎ | ŋ ᨂ | |
| Liquids | | l ᨒ, r ᨑ | | | |
| Glides | w ᨓ | | j ᨐ | | |
| Fricatives | | s ᨔ | ɕ ᨍ | | h ᨖ |

/ɲ/ uses the authentic Lontara nya (ᨎ); /ɕ/ uses ᨍ (the Lontara ja), which is free because /j/ takes ᨐ (ya).

## Vowels

| Vowel        | Lontara | Example (with na) |
| ------------ | ------- | ----------------- |
| i            | ᨗ       | ᨊᨗ (ni)           |
| e            | ᨙ       | ᨊᨙ (né)           |
| a (inherent) | —       | ᨊ (na)            |
| o            | ᨚ       | ᨊᨚ (no)           |
| u            | ᨘ       | ᨊᨘ (nu)           |
| ə/ø          | ᨛ       | ᨊᨛ (nə)           |

ᨛ does triple duty: it writes the vowel ə/ø, serves as a virama (killing the inherent a), marks a glottal stop, and indicates consonant clusters.

Vowel-initial syllables and vowel hiatus are written with the ᨕ carrier (i = ᨕᨗ; ti.e.ta = ᨈᨗᨕᨙᨈ). A nasal coda is written with the nasal letter plus the ᨛ virama (lun = ᨒᨘᨊᨛ). When a hiatus ᨕ onsets a nasal-final syllable it is pronounced as a true glottal stop, so the syllable canon V/CV/CVN is never violated: pien = pi.ʔen, lian = li.ʔan.
