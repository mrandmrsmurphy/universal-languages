# Lexicon

> Parent: [[Interslavic]] · Basic list: [[Interslavic/Swadesh]] · Sounds: [[Interslavic/Phonology]] · Script: [[Interslavic/Orthography]]

Dictionary of Interslavic words, one file per word, each derived from its Proto-Slavic source (see [[Interslavic/Anthropology]]). The file name and title are the Cyrillic spelling; the Latin romanization is a row in the entry.

## Entry format

Title is the Cyrillic spelling, followed by a table with these rows (omit a row that doesn't apply):

| Row | Content |
| --- | --- |
| Latin | Romanization |
| IPA | Per [[Interslavic/Phonology]] |
| Part of speech | |
| Gender | For nouns |
| Gloss | English meaning |
| Proto-Slavic | Source form, with its Proto-Indo-European source if known |
| Etymology | Full source chain when it passes through other stages (e.g. Old East Slavic), in place of Proto-Slavic |
| Compare | Reflexes in Eastern, Western and Southern Slavic |
| Swadesh | № in [[Interslavic/Swadesh]], if any |

Pronouns and other inflected words get a Forms table.
