# Orthography

> Parent: [[Ortatürk]]

Ortatürk's long-term script is Armenian — a revival with precedent: Armeno-Kipchak was Turkic written in Armenian letters for centuries. The upstream Latin orthography (a ä b c ç d e f g ğ h ı i j k l m n ñ o ö p q r s ş t u ü y z, with w in loans) is accepted temporarily.

## Consonants

| | Labial | Dental/Alv. | Postalv./Palatal | Velar | Back |
| --- | --- | --- | --- | --- | --- |
| Nasal | /m/ Մ մ | /n/ Ն ն | | /ŋ/ նկ | |
| Voiceless plosive | /p/ Պ պ | /t/ Տ տ | /tʃ/ Ճ ճ | /k/ Կ կ | /q/ Ք ք |
| Voiced plosive | /b/ Բ բ | /d/ Դ դ | /dʒ/ Ջ ջ | /ɡ/ Գ գ | |
| Voiceless fricative | /f/ Ֆ ֆ | /s/ Ս ս | /ʃ/ Շ շ | /x~χ/ Խ խ | /h~ħ/ Հ հ |
| Voiced fricative | /v~w/ Վ վ | /z/ Զ զ | /ʒ/ Ժ ժ | /ɣ~ʁ/ Ղ ղ | |
| Approximant | | /l/ Լ լ | /r/ Ռ ռ | /j/ Յ յ | |

Upstream Latin correspondences: c = ջ, ç = ճ, ğ = ղ, h = խ, j = ժ, ñ = նկ, q = ք, ş = շ, y = յ. /ŋ/ is the digraph նկ.

## Vowels

| | Front | Back |
| --- | --- | --- |
| High unrounded | /i/ ի | /ɯ/ ը |
| High rounded | /y/ և | /u/ ու |
| Low unrounded | /e/ ե · /æ/ է | /a/ ա |
| Low rounded | /ø/ ո | /o/ օ |

Upstream Latin: a ա · ä է · e ե · i ի · ı ը · o օ · ö ո · u ու · ü և.

## Examples

- Ortatürk = Օրտատևրկ
- Öztürk tili = Ոզտևրկ տիլի
- Öztürkçe = Ոզտևրկճե

Note: և (/y/) is also the Armenian word "and" and its commonest digraph — context must disambiguate.
